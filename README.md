### 📦 LogiControl

Sistema desenvolvido em **Python** para automação e validação de dados de estoque e movimentações logísticas.

O projeto tem como objetivo reduzir erros de preenchimento, automatizar cálculos e transformar dados de uma planilha Excel em informações mais organizadas e úteis.

**Tecnologias:**

`Python` `Pandas` `OpenPyXL` `Excel`
